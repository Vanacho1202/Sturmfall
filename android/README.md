# Sturmfall – Android-App

Die App ist eine Hülle (WebView) um https://sturmfall.onrender.com. Jedes Update am Spiel ist sofort in der App, ohne neue APK.

Bauen (Windows): `gradlew.bat assembleRelease` → `app\build\outputs\apk\release\app-release.apk`
Die fertige APK liegt im Spiel unter `public/Sturmfall.apk` (Download: https://sturmfall.onrender.com/app).
